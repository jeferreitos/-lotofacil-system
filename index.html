Atualizar resultados da Lotofácil

Busca o concurso mais recente na API e salva no banco. As abas de Ciclos, Análise, Matriz de atraso e Conferência são recarregadas automaticamente depois.

Lançar concurso manualmente

Use isso quando a busca automática na API estiver falhando. Informe o número do concurso, a data do sorteio e as 15 dezenas sorteadas. O concurso é gravado na mesma tabela usada pelos resultados importados automaticamente, então passa a valer em Ciclos, Gerar jogos, Meus jogos, Conferência e Análise, do mesmo jeito que um concurso importado pela API. Se você digitar de novo o número de um concurso já lançado, os dados dele são atualizados (substituídos), em vez de duplicar a linha.

Cada jogo é pontuado de 0 a 100 com base na frequência histórica de cada critério (soma, pares/ímpares, repetidas, primos, moldura, fibonacci e mágicos), calculada pela function gerar_jogos do banco. O primeiro jogo da lista é o Jogo Âncora (maior nota).
